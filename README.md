### 👋 Sobre

Construo **sites, sistemas e automações com IA** pra negócios crescerem — do micro-empreendedor ao produto multi-stack.

Não entrego mockup: **software em produção, com cliente usando.** Cada projeto com URL no ar e resultado que dá pra medir.

Venho da **automação industrial crítica** (instrumentação e fiscalização de obras na Petrobras) — onde software que falha para uma linha de produção inteira. Trouxe essa régua pra cada projeto: tem que aguentar a pressão, todo dia, sem cair.
